# 切り抜き動画ツール（Windows）

長い動画から、指定した秒数の切り抜き（ダイジェスト）動画を自動で作るツールです。

## ダウンロード
https://github.com/04tetsu03ya/kirinuki-tool/releases/download/latest/KirinukiTool-Setup-Windows.exe

2回目以降は、アプリが起動時に新しいバージョンを確認して自動で更新できます。

## できること
- **おまかせ**：全体を区間に分け、各区間から音や動きが盛り上がっている場面を選ぶ（全体の雰囲気が伝わる）
- **範囲を指定**：指定した範囲の中からおまかせで選ぶ／範囲をそのまま使う
- 出来上がりの長さ・1カットの長さを指定
- 話している言葉を自動でテロップに（一覧で修正・追加できる）
- テロップの見た目：同梱の日本語フォント14種類＋パソコンの日本語フォント、文字・ふちの色、大きさ。全体の設定はいつでも変更でき、テロップごとに個別にも変えられる（プレビューにすぐ反映）
- 効果音（内蔵8種類＋自分の音）、元の音の音量、カットごとの音量、音量の自動調整
- カットの並べ替え・削除・開始/終了の調整・「別の場面に替える」
- 横 16:9 ／ 縦 9:16（形が違うときは、ぼかした映像で埋める or 中央を切り抜く）
- タイムライン（カットの位置と音の大きさを表示、カットの端をドラッグで調整、拡大率スライダー／Ctrl＋ホイール）
- プレビューの再生速度 1倍・1.5倍・2倍、プレビューの音量（書き出しの音量は変わらない）
- プレビューは出来上がりの形（横 16:9／縦 9:16）の枠で表示
- プロジェクトの保存・読み込み

## 使っている素材
- フォント：Noto Sans JP、デラゴシック、ロックンロール、レゲエ、もっちーポップ、M PLUS Rounded、Zen角ゴシック、Zen丸ゴシック、キウイ丸、はちまるポップ、マジック、ステッキ、しっぽり明朝、ドットゴシック16（すべて SIL Open Font License。assets/fonts/licenses）
- 効果音：このツールのために数式で作ったもの
- 動画処理：FFmpeg（GPL ビルド）／文字起こし：faster-whisper
